# green-re

หน้าเว็บทางเข้าของ **ระบบติดตามทรัพยากรและพลังงาน Green Somdej (QSMH)**
มีหน้าปกแนะนำระบบ ภาพรวมล่าสุดที่ดึงจากระบบจริง และปุ่มเข้าแดชบอร์ด

> ข้อมูลและการคำนวณทั้งหมดยังอยู่ใน Google Apps Script ของโรงพยาบาล
> หน้านี้ไม่เก็บข้อมูลเอง เป็นไฟล์ HTML ไฟล์เดียว ไม่ต้อง build

## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (หน้าปก ภาพรวมล่าสุด วิเคราะห์เชิงลึก ความสามารถ วิธีใช้ ลิงก์ด่วน คำถาม) |
| `README.md` | ไฟล์นี้ |

### ติดตั้งใน Apps Script (ครั้งเดียว)

1. เพิ่มไฟล์สคริปต์ใหม่ชื่อ `DeepInsight` (ชนิด Script) แล้ววางเนื้อหาจาก `DeepInsight.gs`
2. เพิ่มไฟล์ HTML ใหม่ชื่อ `DeepInsightUI` แล้ววางเนื้อหาจาก `DeepInsightUI.html`
   (Apps Script ไม่ยอมให้ไฟล์ .gs และ .html ชื่อซ้ำกัน จึงต้องลงท้าย `UI`)
3. ในไฟล์ `Index.html` เพิ่มบรรทัดนี้ต่อจาก `<?!= include('JsInsights'); ?>` (ใกล้ท้ายไฟล์)

   ```html
   <?!= include('DeepInsightUI'); ?>
   ```

4. **Deploy → Manage deployments → แก้ไข → Version: New version → Deploy** (ลิงก์เดิมไม่เปลี่ยน)

เมนู "📈 วิเคราะห์เชิงลึก" จะขึ้นใต้เมนูน้ำมันเชื้อเพลิงเอง ไม่ต้องแก้ `JavaScript.html`
ลิงก์ `.../exec?tab=deep` เปิดแดชบอร์ดที่หน้านี้ทันที (ปุ่ม "เปิดหน้าวิเคราะห์เชิงลึก" ในหน้า green-re ใช้ลิงก์นี้)
ใช้ขอบเขต (กลุ่ม Green / ทั้งโรงพยาบาล) และรอบรายงาน (ปี พ.ศ. / ปีงบ) จากแถบด้านบนร่วมกับหน้าอื่น

### ติดตั้งใน Apps Script (ครั้งเดียว)

3. เพิ่มไฟล์ Script ชื่อ `ExecSlides` วางเนื้อหาจาก `ExecSlides.gs`
4. เพิ่มไฟล์ HTML ชื่อ `ExecSlidesUI` วางเนื้อหาจาก `ExecSlidesUI.html`
5. ในไฟล์ `Index.html` เพิ่ม 2 บรรทัดนี้ต่อจาก `<?!= include('DeepInsightUI'); ?>`


6. **Deploy → Manage deployments → แก้ไข → Version: New version → Deploy**

หน้า QR code เดิม (`FuelEntry.html`) ยังใช้ได้เหมือนเดิม และใช้กติกาเลขไมล์ชุดเดียวกัน

## ขั้นตอนขึ้น GitHub Pages

1. ใน Apps Script ให้อัปเดตไฟล์ `Code.gs`, `Index.html` และ `Embed.html` ตามเวอร์ชันล่าสุด แล้ว **Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version → Deploy**
   (ใช้ deployment เดิม ลิงก์จึงไม่เปลี่ยน · เวอร์ชันนี้มีด่านรหัสเจ้าหน้าที่ 7 หลัก และการ์ดภาพรวมขนาดใหญ่)
2. เปิดแดชบอร์ด กดปุ่ม **🔗 ลิงก์ฝังหน้าเว็บอื่น** แล้วคัดลอกลิงก์
3. เปิด `index.html` หาส่วน `CONFIG` ใกล้ท้ายไฟล์ แล้ววางลิงก์ในค่า `embedUrl`

   ```js
   const CONFIG = {
     embedUrl: 'https://script.google.com/macros/s/xxxx/exec?page=embed&t=xxxx',
     appUrl: '',                 // เว้นว่างได้
     defaultScope: 'hospital',   // 'hospital' | 'green'
     defaultPeriod: 'calendar'   // 'calendar' (ปี พ.ศ.) | 'fiscal' (ปีงบประมาณ)
   };
   ```

4. ที่ GitHub สร้าง repository ชื่อ `green-re` แล้วอัปโหลด `index.html` และ `README.md`
5. ไปที่ **Settings → Pages** เลือก Source เป็น **Deploy from a branch**, Branch `main`, โฟลเดอร์ `/ (root)` แล้วกด Save
6. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้ GitHub>.github.io/green-re/`

ถ้ายังไม่ใส่ `embedUrl` หน้าเว็บยังเปิดได้ ส่วนภาพรวมจะแสดงข้อความว่ายังไม่ได้เชื่อมต่อข้อมูล และปุ่มลิงก์จะกดไม่ได้

## เรื่องที่ควรรู้

- **repository แบบ public = ทุกคนเห็นลิงก์ฝัง:** ใครเปิดลิงก์นี้ได้จะเห็นการ์ดภาพรวม (ยอดสะสมและ % เทียบปีฐาน) แต่แก้ไขข้อมูลไม่ได้
  ถ้าไม่ต้องการให้คนนอกเห็น ให้ใช้ repository แบบ private (GitHub Pages แบบ private ต้องใช้บัญชีแบบเสียเงิน)
  ถ้าลิงก์หลุด กด **♻️ สร้างลิงก์ใหม่ (ยกเลิกลิงก์เดิม)** ในหน้าลิงก์ฝังของแดชบอร์ด แล้วนำลิงก์ใหม่มาใส่แทน
- **ภาพรวมจะแสดงได้เมื่อเว็บแอป deploy แบบ "ทุกคน (Anyone)":** ถ้า deploy แบบเฉพาะคนในองค์กร คนนอกจะเห็นหน้าให้ลงชื่อเข้าใช้แทนการ์ด
  และการเข้าแดชบอร์ดยังเป็นไปตามสิทธิ์ที่ตั้งไว้ใน Apps Script เสมอ
- **ไม่ให้เว็บค้นหาเก็บหน้านี้:** ถ้าต้องการให้ Google ค้นหาเจอ ให้ลบบรรทัด `<meta name="robots" content="noindex">`
- **ธีมมืด/สว่าง** เปลี่ยนตามการตั้งค่าของเครื่องผู้ใช้อัตโนมัติ (โทนน้ำเงิน-ขาว พื้นหลังมีลายตัวอักษร Green Somdej)
- **แอนิเมชัน** ปิดอัตโนมัติสำหรับผู้ที่ตั้งค่าเครื่องให้ลดการเคลื่อนไหว
- **รหัสเจ้าหน้าที่ 7 หลัก:** ก่อนเข้าแดชบอร์ดต้องกรอกรหัส ระบบตรวจว่าเป็นตัวเลข 7 หลัก แล้วบันทึกเวลาและรหัสในแท็บ `AccessLog` ของ Google Sheet (สร้างให้อัตโนมัติ) เครื่องเดิมจำไว้ 12 ชั่วโมง
  เป็นการระบุตัวผู้เข้าใช้ ไม่ใช่รหัสผ่าน ระบบไม่ได้เทียบกับรายชื่อเจ้าหน้าที่จริง
- **ไม่เห็นลิงก์ Apps Script:** แดชบอร์ด หน้าบันทึกน้ำมัน และภาพรวมเต็มจอ เปิดซ้อนอยู่ในหน้า green-re แถบที่อยู่จึงเป็น `.../green-re/#dashboard`  (ลิงก์ Apps Script ยังอยู่ใน `CONFIG` ของไฟล์ `index.html` ซึ่งใครเปิดดูซอร์สก็เห็นได้)
