# green-re

หน้าเว็บทางเข้าของ **ระบบติดตามทรัพยากรและพลังงาน Green Somdej (QSMH)**
มีหน้าปกแนะนำระบบ ภาพรวมล่าสุดที่ดึงจากระบบจริง และปุ่มเข้าแดชบอร์ด

> ข้อมูลและการคำนวณทั้งหมดยังอยู่ใน Google Apps Script ของโรงพยาบาล
> หน้านี้ไม่เก็บข้อมูลเอง เป็นไฟล์ HTML ไฟล์เดียว ไม่ต้อง build

## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (หน้าปก ภาพรวมล่าสุด ความสามารถ วิธีใช้ ลิงก์ด่วน คำถาม) |
| `README.md` | ไฟล์นี้ |

## ขั้นตอนขึ้น GitHub Pages

1. ใน Apps Script ให้อัปเดตไฟล์ `Embed.html` ตามเวอร์ชันล่าสุด แล้ว **Deploy → Manage deployments → New version**
   (เวอร์ชันนี้ส่งความสูงของการ์ดออกมา กรอบภาพรวมบนหน้าเว็บจะได้พอดี ไม่มีแถบเลื่อนซ้อน)
2. เปิดแดชบอร์ด กดปุ่ม **🔗 ลิงก์ฝังหน้าเว็บอื่น** แล้วคัดลอกลิงก์
3. เปิด `index.html` หาส่วน `CONFIG` ใกล้ท้ายไฟล์ แล้ววางลิงก์ในค่า `embedUrl`

   ```js
   const CONFIG = {
     embedUrl: 'https://script.google.com/macros/s/xxxx/exec?page=embed&t=xxxx',
     appUrl: '',                 // เว้นว่างได้
     defaultScope: 'hospital',   // 'hospital' | 'green'
     defaultPeriod: 'calendar'   // 'calendar' (ปี พ.ศ.) | 'fiscal' (ปีงบประมาณ)
   };
   ```

4. ที่ GitHub สร้าง repository ชื่อ `green-re` แล้วอัปโหลด `index.html` และ `README.md`
5. ไปที่ **Settings → Pages** เลือก Source เป็น **Deploy from a branch**, Branch `main`, โฟลเดอร์ `/ (root)` แล้วกด Save
6. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้ GitHub>.github.io/green-re/`

ถ้ายังไม่ใส่ `embedUrl` หน้าเว็บยังเปิดได้ ส่วนภาพรวมจะแสดงข้อความว่ายังไม่ได้เชื่อมต่อข้อมูล และปุ่มลิงก์จะกดไม่ได้

## เรื่องที่ควรรู้

- **repository แบบ public = ทุกคนเห็นลิงก์ฝัง:** ใครเปิดลิงก์นี้ได้จะเห็นการ์ดภาพรวม (ยอดสะสมและ % เทียบปีฐาน) แต่แก้ไขข้อมูลไม่ได้
  ถ้าไม่ต้องการให้คนนอกเห็น ให้ใช้ repository แบบ private (GitHub Pages แบบ private ต้องใช้บัญชีแบบเสียเงิน)
  ถ้าลิงก์หลุด กด **♻️ สร้างลิงก์ใหม่ (ยกเลิกลิงก์เดิม)** ในหน้าลิงก์ฝังของแดชบอร์ด แล้วนำลิงก์ใหม่มาใส่แทน
- **ภาพรวมจะแสดงได้เมื่อเว็บแอป deploy แบบ "ทุกคน (Anyone)":** ถ้า deploy แบบเฉพาะคนในองค์กร คนนอกจะเห็นหน้าให้ลงชื่อเข้าใช้แทนการ์ด
  และการเข้าแดชบอร์ดยังเป็นไปตามสิทธิ์ที่ตั้งไว้ใน Apps Script เสมอ
- **ไม่ให้เว็บค้นหาเก็บหน้านี้:** ถ้าต้องการให้ Google ค้นหาเจอ ให้ลบบรรทัด `<meta name="robots" content="noindex">`
- **ธีมมืด/สว่าง** เปลี่ยนตามการตั้งค่าของเครื่องผู้ใช้อัตโนมัติ (โทนน้ำเงิน-ขาว พื้นหลังมีลายตัวอักษร Green Somdej)
- **แอนิเมชัน** ปิดอัตโนมัติสำหรับผู้ที่ตั้งค่าเครื่องให้ลดการเคลื่อนไหว
